Monsterlings — Support

Thanks for playing Monsterlings, the cozy space merge puzzle.

Need help or found a bug?

Email pouyan.meishany@gmail.com and include:

  • your device model and iOS version
  • the content version shown at the bottom of the start screen
  • what happened, and what you expected instead

Report a name on the Hall of Fame

Leaderboard names are typed by players. If one is offensive, you can flag it without leaving the game: open HALL OF FAME, tap REPORT, select every name that doesn't belong, and tap SEND. Entries reported by several players are hidden automatically and reviewed.

You can also email the address above with the name and roughly when you saw it — we can remove any entry and stop a name being used again.

Common questions

Does the game need internet? No — it plays fully offline. When online, it quietly fetches small content updates so you always have the latest monsters and tuning.

Ads or purchases? None. The game is free, with no ads and no in-app purchases.

The leaderboard? Optional. Submitting a name sends only that name, your result, and a random install number — see the privacy policy for exactly what that means.
